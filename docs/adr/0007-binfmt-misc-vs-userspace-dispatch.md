# ADR-0007: binfmt_misc для удобства, userspace для решений

- Статус: принято (2026-10-13).
- Контекст: `binfmt_misc` умеет запускать `./prog.exe` через Wine одной
  строкой. Соблазн — построить на нём всю диспетчеризацию.
- Решение: binfmt_misc — только удобство для тривиальных случаев
  (записи в `binfmt.d/`, как у Arch). Все решения — в `tahoe-uel`.
- Причины (проверено по докам ядра): матчер байтовый, не парсер; нет
  предикатов на поля ELF; `PE\0\0` вне 128-байтного окна; коллизия
  `cafebabe` с Java; порядок записей хрупкий («позже — раньше»);
  нет уверенности, нет caveat, нет выбора эмулятора под arch хоста.
- Последствия: UEL не доверяет порядку binfmt; неоднозначное и
  кросс-арх идёт явным путём UEL с префиксом, окружением и confidence.
