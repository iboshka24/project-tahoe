# ADR-0004: DMG никогда не исполняется

- Статус: принято (2026-10-13).
- Контекст: пользователь приносит `.dmg` с macOS и ждёт «установки».
- Решение: DMG — данные. Read-only монтирование/извлечение → поиск
  `.app` → probe внутреннего Mach-O. Пути исполнения DMG не существует.
- Причины: DMG — образ диска (UDIF), а не бинарь; `koly`-трейлер в конце
  файла; исполнение образа бессмысленно и опасно.
- Последствия: UEL отклоняет DMG на входе probe с явной причиной и
  предлагает смонтировать; отдельный код пути «mount → walk → probe».
