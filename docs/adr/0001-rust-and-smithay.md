# ADR-0001: Rust + Smithay для композитора

- Статус: принято (2026-10-13).
- Контекст: нужен Wayland-композитор. Альтернативы: wlroots (C),
  свой стек (как Hyprland), Smithay (Rust).
- Решение: Rust + Smithay 0.7 с crates.io, MSRV 1.87.
- Причины: Smithay активен (коммит 2026-10-12), MIT, оба профиля
  (winit + TTY) проверенно собираются у нас; у команды уже есть Rust.
  Прецеденты: cosmic-comp, niri — оба на Smithay.
- Последствия: следим за `Unreleased`-изменениями master; не пиним git
  без причины; API 0.x может ломаться — держим слой изоляции тонким.
