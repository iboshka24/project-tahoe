# ADR-0002: Слои совместимости — отдельные процессы

- Статус: принято (2026-10-13).
- Контекст: Wine (LGPL-2.1) и Darling (GPL-3.0) нужны для PE и Mach-O.
- Решение: только `fork`/`exec` + pipes/D-Bus. Никакой линковки GPL-кода
  в наши бинарники. UEL — супервизор, а не загрузчик.
- Причины: юридическая чистота (GPL FAQ `#MereAggregation`), изоляция
  падений, независимые обновления, отдельные префиксы и cgroup-лимиты.
- Последствия: нужен супервизор процессов (этап 2); накладные расходы
  IPC приемлемы — это интерактивные приложения, а не горячий цикл.
