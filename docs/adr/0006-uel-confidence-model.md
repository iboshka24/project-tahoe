# ADR-0006: UEL сообщает уверенность, а не гарантии

- Статус: принято (2026-10-13).
- Контекст: проекты совместимости обычно врут: «нашли MZ — значит,
  Windows-приложения работают».
- Решение: `ExecutionPlan` всегда идёт в паре с `Confidence`
  (`Verified` / `Plausible` / `Layer { caveat }` / `Speculative` / `Refused`).
  Неоднозначности (`cafebabe`) — первоклассный результат, а не угадайка.
- Причины: честная телеметрия успешности — единственный путь к реальному
  улучшению; ложные обещания убивают доверие быстрее, чем честные отказы.
- Последствия: UI обязан показывать caveat для `Layer`; телеметрия пишет
  пару (probe, strategy, исход) в журнал.
