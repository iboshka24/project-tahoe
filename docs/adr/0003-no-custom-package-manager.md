# ADR-0003: Без собственного пакетного менеджера

- Статус: принято (2026-10-13).
- Контекст: соблазн «своего менеджера пакетов для Tahoe».
- Решение: немодифицированные `pacman` + репозитории Arch + свои
  `tahoe-*` репозитории. Форк пакетного менеджера запрещён.
- Причины: безопасность обновлений, подпись, reproducible builds (~79%
  у upstream) — всё это мы получили бы в наследство как вечный долг.
- Последствия: наши PKGBUILDs следуют Arch guidelines (SPDX, 0BSD для
  источников); атомарные обновления — только через `systemd-sysupdate`
  для базового образа, как опция.
