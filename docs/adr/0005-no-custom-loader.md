# ADR-0005: Без собственного загрузчика PE/Mach-O

- Статус: принято (2026-10-13).
- Контекст: соблазн «написать свой лоадер, чтобы не тащить Wine/Darling».
- Решение: не пишем. PE — Wine, Mach-O — Darling. Точка.
- Причины: загрузчик — это 5% работы; 95% — ABI ядра, сотни syscalls,
  тысячи семантик фреймворков. У Wine 30+ лет истории, у Darling 13 лет —
  и оба до сих пор с пробелами. Наш лоадер без отдельного обоснования —
  это годы работы с результатом хуже.
- Последствия: пересмотр только при письменном обосновании с оценкой
  объёма (syscall coverage, TLS, исключения, динамический линковщик).
