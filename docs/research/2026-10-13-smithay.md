# Исследование: Smithay и экосистема Wayland-композиторов

> Дата: 2026-10-13. Источники — первичные: raw.githubusercontent.com,
> api.github.com, crates.io. Полный отчёт суб-агента сохранён в истории
> сессии; здесь — выжимка, достаточная для проектных решений.

## Проверено

- **Smithay** (https://github.com/Smithay/smithay): один крейт-библиотека
  (`src/`) + воркспейс (`anvil`, `smallvil`, `smithay-drm-extras`).
  Лицензия **MIT** (не dual). Релиз crates.io **0.7.0** (2025-06-24,
  `rust-version = "1.80.1"`, edition 2021); `master` — edition 2024,
  `rust-version = "1.87"`, большой `## Unreleased` в CHANGELOG.
  Активен: последний коммит 2026-10-12, 103 открытых PR.
- Модули: `backend`, `desktop`, `input`, `output`, `utils`, `wayland`
  (48 подмодулей), `xwayland`, `reexports`. Фреймворка нет — `main()`,
  `Display::new()`, `ListeningSocket`, `calloop` пишем сами.
- Минимальный набор хендлеров: `CompositorHandler`, `ShmHandler`,
  `BufferHandler`, `SeatHandler`, `XdgShellHandler`, `SelectionHandler`,
  `DataDeviceHandler`, `WaylandDndGrabHandler`, `PointerConstraintsHandler`
  + `delegate_dispatch2!(App)`.
- Бэкенды: `backend_winit` (вложенный, для разработки), `backend_x11`,
  `backend_drm`+`gbm`+`egl`+`libinput`+`session_libseat`+`udev` (реальный TTY).
  Точный список фич — в отчёте; `default` включает почти всё.
- Wayland-протоколы: `wayland-server 0.31.x`, `wayland-backend 0.3.x`,
  `wayland-protocols 0.32.x`.
- **smithay-client-toolkit** 0.21.1, MIT — клиентская сторона (для shell).
- Сравнение: **cosmic-comp** (Rust, Smithay, `GPL-3.0-only`),
  **niri** (Rust, Smithay, `GPL-3.0-or-later`), labwc (C, wlroots),
  Hyprland (C++, свой стек), river (Zig, wlroots), gamescope (C++, wlroots).

## Не проверено

- Номер следующего релиза Smithay (в `master` всё ещё `0.7.0`).
- Внутренний рендер-стек Hyprland; лицензия river по файлу LICENSE.

## Решение для Tahoe

Пин `smithay = "0.7"` с crates.io (не git), MSRV 1.87, два профиля фич:
`winit` (разработка) и `tty` (поставка). См. ADR-0001.
