# CONTRIBUTING.md — Project Tahoe

## Принципы

1. **Границы слоёв.** Композитор, оболочка, UEL и слои совместимости
   общаются через процессы, а не через линковку. GPL-код никогда не
   линкуется в наши крейты (см. `LICENSING.md` §3).
2. **Честность вместо оптимизма.** Формат ≠ совместимость. Каждое
   утверждение о внешнем проекте — со ссылкой на источник и датой
   проверки. Непроверенное помечается `UNVERIFIED`.
3. **Тест на каждое утверждение о формате.** Новый magic, новый парсер —
   новый фикстуры-тест в `crates/tahoe-format`.

## Как начать

```sh
cargo test                        # всё должно быть зелёным
cargo clippy --all-targets -- -D warnings
cargo fmt --all -- --check
```

Требуется Rust ≥ 1.87 (MSRV Smithay 0.7, см. `rust-toolchain.toml`).

## Правила кода

- Rust edition 2024, `cargo fmt`, `clippy` без предупреждений.
- Каждый публичный тип — с doc-комментарием, каждый `unsafe` — с
  обоснованием в комментарии (в идеале `unsafe` вообще нет).
- `tahoe-core`: только типы, никакого I/O.
- `tahoe-format`: только парсинг байтов, никакого `exec`, никаких
  сетевых вызовов.
- `tahoe-uel`: чистые функции решения + тонкий CLI; запуск процессов —
  только через супервизор (этап 2, пока отсутствует).
- Коммиты: короткие, в повелительном наклонении, на английском.

## Документация

- Исследование — в `docs/research/YYYY-MM-DD-тема.md` с разделом
  «Проверено / Не проверено» и ссылками.
- Архитектурные решения — в `docs/adr/NNNN-название.md`.
- Не выдумывайте API, версии и результаты тестов.
